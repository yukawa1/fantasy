Models you save with Save model are kept in ~/.fantasy_agn/models and listed here; a model file from someone else can be loaded with From a file.

Start with a power-law continuum and add the lines, templates and continuum components the spectrum needs with Add component. You can also start from a preset and change it: every model can be edited.

Components
    Initial guess

    Initial values and limits of the selected component. Line fluxes are solved exactly, so they have no bounds. Any single parameter can be fixed or tied to another one in the last columns.
