FANTASY 2.0.2 / The app, step by step

3 · Model

A model is a sum of components. Start from the recommended preset, a preset of your choice, an empty model or a saved model, then add, remove and tune components.

Classification card

Classify spectrum runs fa.classify (starlight, broad Hα, BPT diagrams; see Classification) and recommends a model; Use recommended model applies it.

Compare models on this spectrum

Compare models fits variants of the recommended preset in the background (about a minute): one broad component more and fewer, and each on/off option of the preset switched on its own (host galaxy, outflow wing, coronal lines, O I 6046, Fe II, Balmer continuum, ...), then the preset with every change that helped. Options that change the fitted range (the red side) are left out, because the models are ranked by BIC = χ² + k ln n, which needs the same pixels: every free parameter costs ln n, and ΔBIC < −10 is strong evidence for a change (Kass & Raftery 1995).

recommended
the lowest BIC among the models that put no new parameter at a limit (a limit the preset already hits is not held against them). A change must beat the preset by ΔBIC < −10; otherwise the preset stays recommended.
lowest BIC
shown when it is not the recommended one, with the number of its parameters at a limit: those values are set by the limits, not by the data.
The model choice matters here
across the five best models, the main measurements (broad FWHM, MBH, RFe II, Balmer decrement) move by more than their fit errors: quote the spread, or use Model uncertainty in the Fit step.

Click a card or a row of All candidates to see its fit, its components, the comparison with the preset and its code. Use this model runs that code as a cell of the session; Customize… opens it in the model builder.

The model builder

+ Your own model (or Open in the model builder under the components) opens a full-screen workspace, starting from the recommended model, the current model, any candidate or an empty one. The model is taken apart into its components, each with every argument of its constructor:

  • switch a component off (it keeps its settings), duplicate it (a third broad component is one click), remove or rename it, or + Add component: any component type, or a named line set as a new line component;
  • for a line component: its role, profile, lines (by name, ion or wavelength, or your own line as name@5310), fixed or bounded flux ratios, FWHM and shift as start value and limits, and the same shift and width as another component;
  • Parameters: the start value, limits, fixed flag and tie (with a factor) of every parameter, to any other parameter of the same kind;
  • click the spectrum to see the catalogued lines there and add one to a component; the plot is the initial guess, split by component, and follows every edit; undo and redo with ⌘Z and ⇧⌘Z; the fit range at the top.

The code under Code is exactly the model: Use this model runs it as a session cell, and Fit and rank it fits it on the spectrum in the background and adds it to the comparison as your model. ← Back (or Esc) keeps your edits: Continue your model brings them back.

Start from

A preset
broad components (1–3), host galaxy, outflow wing, stratified BLR, coronal lines, O I 6046, the red side to 7500 Å. See Presets.
Your own model
a power-law continuum, to which you add components.
A saved model
one of your saved models, or a model file from someone else. See Saved models.

Components

+ Add component opens one dialog for everything: emission or absorption lines from the line list (role broad, narrow or outflow; profile Gaussian, Lorentzian, Voigt, Gauss–Hermite or stratified; width and shift limits; kinematics shared, per line, or tied to another component), continua, Fe II and high-order Balmer templates, the host galaxy, absorption troughs and dust. Click a component to change its profile, tie its shift and width to another one, or edit each parameter: initial value, limits, fixed, tied (Parameters).

Is a tie safe? After a fit of one spectrum, the Shift and width choice of a component says for every possible tie whether it would change the result, judged on that fit where both are free, without a new fit (fa.model_confidence): the probability that the FWHM and flux of the main broad line stay within 5%. safe (above 95%), changes it a little, changes the result, or rejected by the data (the two clearly differ: fit again with the tie and compare in Checks). It is conditional on the free model being right (Model comparison).

The plot shows the initial guess on the reference spectrum with the selected component highlighted: if the guess is far off, the limits are probably wrong.

Save model… above the component list keeps the model (with every limit and tie) to use it again; Download gives the JSON file to share.
