Multi-epoch fitting

Several spectra of one object are fitted jointly: what does not vary is shared, and the shared narrow lines calibrate the epochs against each other.

Parameters matching the shared patterns (by default every narrow-line parameter and, with a stellar host, the host: one set of template weights, σ★ and v★) are the same in every epoch; the continuum, Fe II and broad lines vary. With intercalibration each epoch k has a flux scale sk (the reference epoch, the one of highest S/N, has s = 1):

Mk(λ) = sk [ N(λ) + Vk(λ) ]

with N the shared and Vk the varying part. calibration_degree=1 or 2 makes sk(λ) a smooth polynomial, anchored by narrow lines at both ends of the range.

me = fa.fit_epochs(spectra, fa.presets.hbeta(broad_components=2), n_jobs=-1)
me.light_curve(); me.plot_light_curves(); me.plot_baldwin()
me.plot(epoch=5)              # me.epochs[5] is the full result of epoch 5
me.scales                     # the flux scale of every epoch, with errors

Every epoch is first fitted on its own (in parallel), which gives the starting values; then all epochs are fitted together with a block-sparse Jacobian.

What else differs between epochs and can be fitted, measured like the flux scale on the shared narrow lines:

me = fa.fit_epochs(spectra, model,
                   wavelength_offsets=True,     # a velocity per epoch: calibration, redshifts of the files
                   epoch_broadening=True,       # a FWHM per epoch, in quadrature: the resolution differs
                   epoch_scaled=("host",))      # one host spectrum, an amplitude per epoch: apertures, seeing
me.offsets; me.broadening; me.redshift()

The broadening is exact for Gaussian lines: a line of FWHM w seen at resolution R has w2 + R2, so an extra b2 on every width is a resolution √(R2 + b2). Each epoch's result keeps the intrinsic widths, and its spectrum carries the broadened resolution.

Two checks of a joint fit:

chk = fa.calibration_check(me)    # every epoch alone, with the joint flux scales: do the shared lines agree?
chk.table; chk.epochs; chk.excess  # excess: calibration noise not in the error bars
sim = fa.simulation_check(me, n=20)  # sets of epochs drawn from the fit and fitted jointly again
Intercalibration on the narrow lines helps only when they are strong: with weak [O III] it adds a few percent of noise per epoch, and FANTASY warns when the median scale error exceeds 2%. For a good pipeline calibration (SDSS) compare with intercalibrate=False.
In scripts on macOS and Windows put the code under if __name__ == "__main__":, otherwise the parallel part runs serially.
