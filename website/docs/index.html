  3. 0:31 · Model — Choose hbeta with two broad components. Inspect the initial guess and the continuum, Fe II, narrow-line and broad-line components.

Measure broad Hβ in Python

After installing this source version, run this example with the bundled SDSS quasar. The FITS file supplies the redshift. This offline example uses the recorded flux. For extinction-corrected fluxes, apply Spectrum.deredden() in the observed frame before to_rest_frame(). The Hβ preset fits the local continuum, Fe II and the line components together.

import fantasy_agn as fa

spectrum = fa.read(fa.examples.path("type1")).to_rest_frame()
model = fa.presets.hbeta(broad_components=2, feii=True)
result = fa.fit(spectrum, model)
hb = result.measure("Hb", ["broad", "broad2"])
print(hb["fwhm"], hb["fwhm_err"])  # km/s
print(hb["flux"], hb["flux_err"])  # in the spectrum's integrated flux units
result.plot()

Passing both broad component names excludes narrow Hβ from the flux and width. Check hb["fwhm_fragile"] for a shoulder near half maximum. For a galaxy with visible stellar absorption, enable the host in the model, for example fa.presets.hbeta(host="pca"). The measurement guide explains line width, dispersion and equivalent width.

Work with the current fitting tools

Find an unknown redshift
Scan the observed spectrum before moving to rest frame. Inspect the alternative redshifts and the lines expected at each one.
Test weak Fe II multiplets
Compare the original fit with the refit after pruning. Weak groups can bias the blend in either direction depending on which groups the data constrain.
Check your fit
Inspect residuals, simulate spectra to test coverage, and compare broad-line measurements across alternative fits.
Work with repeated observations
Inspect the relative flux scales and wavelength offsets from a joint fit, build light curves and estimate reverberation lags.
