FANTASY 2.0.0 / Fitting

How the fit works

FANTASY minimises the weighted squared residuals with exact derivatives, solving the amplitudes exactly at every step, after a data-driven search for the starting values.
χ2(θ) = Σi [Fi − M(λi; θ)]2σi2
  1. Initial guess. The nonlinear parameters of each component (widths, shifts, shapes) are scanned on a grid of 9 values, components carrying most flux first, in three passes. At every grid point the amplitudes are solved exactly by non-negative least squares, so the scan costs only linear solves (fa.guess returns this start).
  2. Variable projection. The model is linear in the amplitudes a and nonlinear in the rest φ: M = A(φ) a. For given φ, a is found by bounded linear least squares (BVLS); a trust-region reflective algorithm then optimises φ on the projected problem, with the exact Jacobian from the components.
  3. Escape and build-up. After convergence each component's nonlinear parameters are re-scanned; a better start restarts the fit. Overlapping components (several broad components, outflow wings) are also fitted by adding them one at a time, and the better of the two solutions is kept, so adding a component cannot make the fit worse.
  4. Unconstrained parameters. Amplitudes of lines without fitted pixels are fixed at zero and reported in r.unconstrained.

Machine-learned starting values

Finding a good start takes most of the time of a fit. For a model with a trained initializer (a small neural network trained on spectra simulated with the model itself), guess="ml" predicts the nonlinear parameters in about a millisecond; the amplitudes, the fit and the uncertainties are unchanged, so a poor prediction costs time, never accuracy.

r = fa.fit(spec, model, guess="ml")    # falls back to the data-driven guess without an initializer
fa.ml.available()                      # the trained initializers

In Python

r = fa.fit(spec, model, wave_range=(4150, 5550))
r.chi2, r.dof, r.rchi2, r.bic, r.n_free
fa.guess(spec, model)        # only the initial guess
