FANTASY 2.1.0 / Getting started

Overview

FANTASY decomposes optical and ultraviolet spectra of active galaxies (quasars, Seyfert 1 and 2, LINERs, star-forming and passive galaxies, nuclear transients) into physical components: continua, the host galaxy, Fe II, broad, narrow and outflowing emission lines, and absorption. It measures the lines, derives black-hole masses and diagnostics, and propagates every uncertainty.

The app follows the five steps above. Each step writes ordinary FANTASY code into the Python session and runs it, so whatever is done by clicking can be repeated, changed or scripted. The bar at the top shows which steps are done; click a step to go back to it. New analysis clears the session; the ⋯ menu opens and saves projects and downloads the session as a script or notebook.

The session is saved after every step (to ~/.fantasy_agn/sessions, or $FANTASY_AUTOSAVE; set it to 0 to switch this off). When the app starts again, or after New analysis, the Read step offers Restore last session, and Open the one before for the session before that: a server restart or a closed terminal no longer loses the work. The saved file is a project like those of the ⋯ menu (a pickle: open only your own).

■ Stop appears in the top bar while a step runs: it ends the worker processes of a parallel run (fits of many epochs, simulations) and interrupts the step at its next progress report or Python step (a single long call into compiled code finishes first). The cell is marked Stopped and what it was computing is not kept; everything before it is.

In five lines of Python

import fantasy_agn as fa
spec  = fa.read("spec-0615-52347-0108.fits").deredden().to_rest_frame()
c     = fa.classify(spec)                         # what kind of object, which model
r     = fa.fit(spec, fa.presets.optical(broad_components=2))
r.lines; r.measure("Hb"); r.bh_mass("Hb"); r.plot()

The session panel

The python · server button at the top (Ctrl+`) opens the session: every cell the app ran, with its output. Type code at the bottom and run it with Shift+Enter; click a cell to edit it and run it again. All cells share one namespace, and the steps read from it, so code and buttons are interchangeable:

nameholds
files, rawthe paths and the spectra as read
spectra, specthe prepared spectra; the spectrum when there is one
modelthe model being built
c, classesa classification; the classifications of several spectra
r, fits, methe fit of one spectrum; epochs fitted one by one; the joint multi-epoch fit
samplea fitted sample

Copy puts the session on the clipboard as a script; .ipynb downloads it as a notebook; ⋯ → Save project keeps everything (cells, outputs, spectra, fits) in one .fantasy file.
