Saving and reopening work

Three kinds of files: projects (everything), results (one object), and models (a recipe).
fileholdshow
.fantasy projectcells with outputs, spectra, models, fitsapp: ⋯ → Save project / Open project
.fantasy resulta FitResult, MultiEpochResult, Classification, Model or Spectrumfa.save(r, "x.fantasy"), fa.load
.json modelcomponents, limits, fixed and tied parametersmodel.save, fa.load_model
script, notebookthe session as codeCopy, .ipynb
.fantasy files are compressed Python pickles: like any pickle they can run code when opened. Open only files you or your collaborators made. Model files are plain data and safe to share.

Stellar templates are not stored in a result (a fit with a host is a few hundred kB); they are read from the template folder when it is opened.
