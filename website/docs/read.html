1 · Read

Choose what you analyse and where the spectra come from. FANTASY recognises the format, the redshift, the wavelength medium, the instrumental resolution and the flux unit when the file has them.

What you analyse

modewhat happens nextin Python
single spectrumdecompose one spectrum and measure its linesfa.fit
sampleclassify and fit many spectra in parallel; one cataloguefa.fit_sample
multi-epochone object at several dates: joint fit, light curves, lagsfa.fit_epochs

Sources

Files
drop them on the page (any number). SDSS spec-*.fits, DESI coadd and SPARCL files, OzDES and GAMA files, 1D FITS spectra, and text files with columns wavelength, flux and (optionally) error.
Path / glob
a path or pattern on this computer, e.g. ~/data/AT2024zkr/*.txt.
DESI TARGETID
fetched from the DESI DR1 via Data Lab (fa.desi.fetch).
SDSS plate-mjd-fiber
fetched from the SDSS DR17 Science Archive Server (fa.sdss.fetch).
File format
automatic recognises the file; choose SDSS, DESI coadd, OzDES (all epochs or one public spectrum), GAMA, 1D FITS or text when it guesses wrong.
Group epochs by
(multi-epoch) the date in the file name (YYYYMMDD), the MJD in the header, or the file order; automatic tries them in that order.
Loaded
the table of what was read (date, name, redshift, position); tick rows and Remove selected to drop them. For large local samples, the table previews the first 20 files. Removing a previewed row preserves the remaining files.

DESI and SDSS spectra are downloaded with Fetch and kept under ~/.fantasy_agn. OzDES files hold the stack and every exposure: fa.read(path, epoch=4) reads one exposure, fa.ozdes.read_epochs(path, combine="night") averages each night.

OzDES spectra are not flux calibrated (counts, different per night). FANTASY then computes no luminosities or masses; widths, shifts, EWs and ratios are fine, and light curves need the intercalibrated multi-epoch fit.
spec = fa.read("spec-0615-52347-0108.fits")
spec = fa.read("my_spectrum.txt", z=0.123, ra="12:34:56.7", dec="+12:34:56")
spec = fa.desi.fetch(39627963565609635)
