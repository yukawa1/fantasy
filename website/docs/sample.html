FANTASY 2.1.0 / Time domain and samples

Fitting a sample

Many spectra at once: each is read, corrected, classified and fitted with the model its class needs, in parallel.
s = fa.fit_sample(glob.glob("data/*.fits"), out="fits/")
s.table              # the catalogue: class, model, χ²ν, main quantities with errors
s.load(3)            # the full fit of row 3
s.gallery()          # an HTML page with every fit

In the app, sort the catalogue by a column (e.g. χ2ν, to check the worst fits first) and click a row to see its fit. Choose a model instead of automatic to fit all spectra with the same one. Every fit is also saved as a .fantasy file.
