Classification

fa.classify(spectrum, wave_range=(3700, 6900), broad_dbic=25.0, broad_snr=5.0, broad_ew=30.0, min_snr=3.0, templates='emiles', verbose=False)

Classify a rest-frame spectrum before choosing a model (see the module documentation for the procedure).

spectrumSpectrum; moved to the rest frame if it is not.
wave_rangerange for the stellar continuum fit (clipped to the data).
broad_dbicminimum BIC improvement for broad lines.
broad_snrminimum S/N of the broad H-alpha (or H-beta) flux.
broad_ewminimum equivalent width (A) of the broad line (thresholds: see the module documentation).
min_snrminimum S/N for a narrow line to enter a diagnostic.
templatesstellar population templates for the starlight ('emiles', 'bc03', ...; see fantasy_agn.templates).
returnsClassification

Classification(spectrum, label, uncertain, reason, measurements, stellar, lines, narrow_fit=None, broad_fit=None, masks=None)

Result of classify: label, uncertain, reason, measurements (dict), model() (recommended Model) and plot().

Classification.plot_steps(fig=None, save=None)

What classify did: the spectrum with the masked lines and the stellar fit, H-alpha in the starlight-subtracted spectrum with the narrow-only and the narrow+broad fit, and the [NII] BPT diagram.

fa.lookup_catalogs(objects, cls=None, radius=3.0, timeout=30, verbose=False)

What public catalogs know about one or many objects, and where they disagree with the fit.

Searches radius arcsec around each position in SIMBAD, NED, Milliquas and AllWISE; radio and X-ray catalogs use radii that suit their positional accuracy (FIRST 3", NVSS 15", XMM 5", Chandra 3", 2RXS 30"). Only the coordinates leave the computer. A service that cannot be reached is named in the unreachable column; the rest of the row still holds.

The redshift check is independent only if the catalog redshift does not come from the same spectrum, which is often the case for SDSS objects.

Example:

fa.lookup_catalogs((187.27792, 2.05239))      # by position
table = fa.lookup_catalogs(sample)            # a whole fitted sample
table[table.n_disagreements > 0][["name", "disagreements"]]
objectsa Spectrum, a file path, a fit, a Classification, a sample (fa.fit_sample), a table with columns ra, dec (degrees; optionally name, z, cls), an (ra, dec) pair, or a list of those.
clsthe class given to a single object (the label of fa.classify), used for the disagreement flags.
radiussearch radius in arcsec for the optical and infrared catalogs.
timeoutseconds to wait for one reply.
returnspandas DataFrame, one row per object in the input order, with catalog_name, catalog_class, catalog_z, the matches of each catalog (simbad_*, ned_*, milliquas_*, wise_*, first_*, nvss_*, xmm_*, chandra_*, rosat_*), disagreements (in words), n_disagreements and unreachable.
