FANTASY 2.1.0 / API reference

Reading data

fa.read(path, format='auto', ra=None, dec=None, coords=None, **kw)

Read a spectrum file. format: 'auto', 'sdss', 'desi', 'ozdes', 'gama', 'fits1d' (linear or log-linear WCS in the primary HDU) or 'text' (2-3 columns: wave, flux, [err]). Extra keywords override what is read (e.g. z=0.1). DESI coadd files hold many targets: pass targetid=... or index=..., and optionally redrock=... for the redshift (see fantasy_agn.desi). OzDES DR2 files hold the stack and every epoch: pass epoch=... for one epoch (see fantasy_agn.ozdes).

spec = fa.read("spectrum.txt", z=0.123, ra="12:34:56.7", dec="+12:34:56").deredden()

ra, decsky position, overriding the file (needed for the Galactic extinction of files without coordinates, e.g. text files): degrees or sexagesimal strings ('12:34:56.7', '+12:34:56'); see parse_coordinates.
coordsthe position as one string ('12:34:56.7 +12:34:56') or a SkyCoord.

Spectrum(wave, flux, err=None, z=None, name='spectrum', medium='vacuum', resolution=0.0, flux_unit=1.0, rest_frame=False, ra=None, dec=None, mjd=None, meta=None, resolution_curve=None)

A 1D spectrum.

wavewavelengths in Angstrom.
fluxflux density (any units; flux_unit records the scale, e.g. 1e-17 erg/s/cm2/A for SDSS, used only for luminosities).
err1-sigma flux uncertainty. Pixels with non-finite or non-positive errors are ignored in fits.
zredshift.
medium'vacuum' or 'air' wavelengths.
resolutioninstrumental FWHM in km/s (0 if unknown). It is removed in quadrature from fitted line widths.
resolution_curveoptional (wavelength, FWHM in km/s) arrays for a resolution that changes with wavelength (e.g. DESI); each line then uses the resolution at its own wavelength.

Spectrum.to_rest_frame(z=None)

Shift to the rest frame: wave/(1+z), flux and err * (1+z).

Spectrum.deredden(ebv=None, r_v=3.1, source='auto', sf11=True)

Correct for Galactic (Milky Way) extinction with the Fitzpatrick (1999) law. Do this once, before measuring fluxes and luminosities.

ebvE(B-V) in magnitudes. If not given it is looked up at the position of the spectrum (see fantasy_agn.extinction.galactic_ebv): the value in the file (DESI), local SFD98 maps (sfdmap2) or the IRSA dust service online, with the Schlafly & Finkbeiner (2011) recalibration when sf11 is True.
source'auto', 'file', 'sfd' or 'irsa' for the lookup.

Spectrum.crop(wmin=None, wmax=None)

Keep wavelengths between wmin and wmax.

Spectrum.mask(*ranges)

Exclude wavelength ranges from fits, e.g. spec.mask((5570, 5585)).

Spectrum.with_resolution(fwhm=None, R=None)

A copy with the instrumental resolution set: fwhm in km/s (FWHM of the line-spread function), or the resolving power R = lambda / FWHM, e.g. spec.with_resolution(R=2000) (150 km/s). It replaces the value (and the resolution curve) of the file. Fitted line widths are then intrinsic: the resolution is removed in quadrature. Text and plain FITS files carry no resolution (0): the widths then include the instrumental broadening.

fa.find_redshift(spectrum, z_range=None, kinds=('galaxy', 'quasar'), n_templates=(5, 4), n_poly=3, n_candidates=5, min_overlap=0.75, min_dchi2=0.2, step_kms=120.0, refine=True, catalog=False)

Redshift of a spectrum from a chi2 scan with galaxy and quasar templates; see the module docstring.

spectruma Spectrum in the observed frame (its z, if any, is not used).
z_range(min, max) redshift to search (default: all that the templates cover: about 0 to 1 for galaxies and 0 to 7 for quasars in an optical spectrum).
kindstemplate sets to try.
n_templatesnumber of eigenspectra of the galaxy and of the quasar set.
n_polyterms of the additive polynomial (3: constant, slope, curvature).
n_candidateshow many minima to keep.
min_overlapfraction of the spectrum that the templates must cover at a redshift.
min_dchi2the best redshift is secure if the next one (more than 1500 km/s away) has a chi2 higher by more than this per pixel. On 540 SDSS spectra of nine classes (z = 0.01-2.5, median S/N 14) 97% of the best redshifts were right (within 1000 km/s of the pipeline's); with 0.2, 96% were called secure and 99.8% of those were right, and of the rest 43%. The SDSS pipeline warns below 0.01, where here most answers were wrong.
step_kmsstep of the search; the minima are then refined on a 25 km/s grid.
refinefor a quasar-template redshift with [OIII]5007 in the range, fit the narrow H-beta and [OIII] lines there and take the redshift from them (method = 'narrow lines') if [OIII] is detected above 5 sigma. Quasar templates follow the broad lines, which are shifted from the systemic velocity by ~100 km/s; the narrow lines much less. The error is then the statistical one of the line centre: against SDSS pipeline redshifts such values scatter by ~50 km/s, which is the disagreement between methods, not noise. Galaxy-template redshifts follow the stars, agree with the pipeline to 4-10 km/s and are not changed.
catalogalso look the position up in SIMBAD, NED and Milliquas (fa.lookup_catalogs; sends the coordinates, needs the spectrum's ra and dec) and report the redshifts found there in catalog and whether one agrees with a candidate; it does not change the choice.
returnsRedshiftResult

fa.desi.fetch(targetid=None, sparcl_id=None, data_release='DESI-DR1', save=None)

Download a public DESI spectrum from NOIRLab's SPARCL service and return it as a Spectrum (the primary spectrum of the target unless sparcl_id is given). save writes the retrieved record as JSON, readable later with from_sparcl(json.load(open(path))[1]).

No account or extra package is needed. Please acknowledge DESI and the Astro Data Lab when you use these data.

fa.desi.find(targetid=None, ra=None, dec=None, radius=2.0, data_release='DESI-DR1', limit=50)

DESI spectra available in NOIRLab's SPARCL service, by TARGETID or by position (ra, dec in degrees, radius in arcsec). Returns a table with sparcl_id, targetid, redshift, spectype, survey, program and whether it is the primary spectrum of the target.
