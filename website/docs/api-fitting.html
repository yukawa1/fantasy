FANTASY 2.0.2 / API reference

Fitting

fa.fit(spectrum, model, wave_range=None, guess=True, errors='covariance', n_mc=100, scale_errors=True, seed=None, n_jobs=None, mcmc=None, build_up=True, verbose=True)

Fit a model to a spectrum.

spectruma Spectrum (usually in the rest frame).
modela Model; it is not modified (the result holds a fitted copy).
wave_range(min, max) wavelengths to fit; default: whole spectrum.
guessestimate initial parameters from the data first (recommended).
errors'covariance' (fast, from the Jacobian), 'mc' (Monte Carlo re-fits of the spectrum perturbed by its errors), 'mcmc' (posterior samples by Hamiltonian Monte Carlo with flat priors within the parameter limits) or None.
mcmcoptions for errors='mcmc': n_chains (4), n_warmup (300), n_samples per chain (600), trajectory (1.6, whitened units), retry (True: chains that have not converged are run again with a 3x longer warm-up and a 2x longer trajectory). result.mcmc_info reports acceptance, split-R-hat, the effective sample size and the number of attempts.
n_mcnumber of Monte Carlo realizations.
scale_errorsif the reduced chi2 > 1, inflate uncertainties by sqrt(reduced chi2) (the error spectrum is then assumed underestimated).
seedrandom seed for the Monte Carlo errors.
n_jobsprocesses for Monte Carlo and for the MCMC chains (default: all cores, or 1 inside the workers of fit_many / fit_sample; 1 = serial). In a script, parallel runs need the code under if __name__ == "__main__": (else it runs serially).
build_upfor models with overlapping components (several broad components of the same lines, outflow wings), also fit by adding them one at a time and keep the better of the two solutions (result.start says which was used).
verboseprint a short summary.
returnsFitResult

fa.guess(spectrum, model, wave_range=None, verbose=False)

Return a copy of model with data-driven initial parameter values.

fa.compare(spectrum, models, quantities=None, tolerance=0.1, n_jobs=-1, **fit_options)

Fit several models to one spectrum and compare them.

modelsdict {name: Model} (e.g. fa.presets.variants("hbeta")).
quantitiesdict {name: function(FitResult) -> (value, error)}; default: broad-line FWHM, sigma and flux of the main broad line and the black-hole mass (see default_quantities).
tolerancemodels with reduced chi2 within this fraction of the best one are acceptable and define the systematic error.
n_jobsprocesses for the fits (-1: all cores but one; 1: one after the other).
fit_optionspassed to fantasy_agn.fit (e.g. errors='mc').
returnsComparison

fa.fit_many(spectra, model, n_jobs=-1, verbose=True, **fit_options)

Fit the same model to many spectra (epochs of one object, or a sample) in parallel processes. Returns a list of FitResult in the order of spectra; a spectrum that cannot be fitted gives the exception instead (with a warning).

n_jobsprocesses (-1: all cores but one; 1: serial). In scripts on macOS and Windows put the code under if __name__ == "__main__":, otherwise the fits run serially.
fit_optionspassed to fit (e.g. wave_range, errors).

fa.fit_sample(files, out=None, model=None, deredden=True, ebv=None, z=None, mask_absorption=False, mask_sky='auto', refine=True, diagnostics=True, prune_feii=False, n_jobs=-1, verbose=True)

Classify and fit many spectra in parallel; returns a SampleResult.

fileslist of paths (any format fa.read knows).
outfolder for the fits (.fantasy) and figures (made if needed); None: catalog only.
modelNone (default): the model the classification recommends for each spectrum; or a preset name ('hbeta', 'seyfert2', ...) or (name, {options}) for all spectra.
dereddencorrect the Galactic extinction (looked up, or ebv).
zredshift for all spectra (when the files have none).
mask_absorptionmask narrow absorption lines (CIV, MgII quasars).
mask_skymask telluric bands and strong sky lines ('auto': for the narrow-line galaxy presets, whose high-S/N fits they would dominate).
refinefor narrow-line galaxies with reduced chi2 > 1.2, add the preset extensions the BIC prefers (fantasy_agn.refine).
prune_feiifit again without the Fe II multiplets the data do not detect (fantasy_agn.prune_feii; True: below 2 sigma, or the number of sigma). Weak Fe II comes out too high otherwise, which moves the weak-Fe II end of a main sequence diagram to the right; with moderate Fe II pruning removes real weak multiplets too, so it is a choice. The catalog gets feii_groups, feii_dropped and the values before pruning (R_FeII all groups, broad Hb FWHM all groups).
n_jobsprocesses (-1: all cores but one).

fa.fit_absorbed(spectrum, model, max_troughs=10, nsigma=4.0, iterations=3, min_dbic=10.0, max_fwhm=6000.0, verbose=False, **fit_options)

Fit model, then add absorption troughs found in the residuals and refit while the BIC improves by more than min_dbic. Returns the best FitResult with result.absorbers (a table of the troughs) and result.no_absorbers (the fit without them).

max_fwhmwidest trough, km/s; each trough may also grow to at most three times the width at which it was found. Wider troughs would trade flux with the emission (a broad shallow "absorber" under a too-broad line).

fa.refine(spectrum, preset, options=None, result=None, min_rchi2=1.2, min_dbic=10.0, max_steps=3, verbose=False, **fit_options)

Fit spectrum with preset (a name in :data:EXTENSIONS, with options) and add extensions while the BIC prefers them (forward selection). Returns the best FitResult with result.refinement (a table of the trials) and result.preset_options (the options of the kept model).

resultan existing fit with the same preset and options (saves one fit).
min_rchi2only refine if the fit has a larger reduced chi2.

fa.prune_feii(result, nsigma=2.0, n_jobs=-1, **fit_options)

Fit again without the Fe II multiplets that the data do not detect.

The amplitude of every multiplet group of an FeII component is free and cannot be negative. Noise then moves a weak or absent group only upwards, so the summed Fe II comes out too high, the continuum too low and the broad line next to it too strong. In simulations of an SDSS quasar at S/N 30 per pixel fitted with presets.hbeta() the Fe II flux was 9% too high at R_FeII = 0.25 and 66% at R_FeII = 0.08, and with no Fe II at all the fit returned R_FeII = 0.12 and a broad H-beta flux 12% too high; with Fe II three times stronger, or noise three times lower, the bias was below 2%.

This step fixes at zero the multiplets whose amplitude is below nsigma times its error (or at its bound) and fits the model again from the solution it was given:

r = fa.fit(spec, fa.presets.hbeta())
r = fa.prune_feii(r)
r.feii_pruning        # multiplet, amplitude, error, kept or dropped

In the same simulations it removed most of the bias where it is large (broad H-beta flux with no Fe II: +15% -> +1%; at R_FeII = 0.08: +6% -> 0%, with a 3 times smaller total error). It has a cost where Fe II is moderate: real but weak multiplets are dropped too, and at R_FeII = 0.25 the Fe II flux came out 13% too low instead of 6% too high (broad H-beta -2% instead of +1%), with the same total error. It is therefore a choice, not a default: use it for weak Fe II and low S/N, and say so with the results. The numbers are from one spectrum and one model; check your own case with simulations.

resulta FitResult with errors (errors='covariance', 'mc' or 'mcmc'), or a list of them (the epochs of fa.fit_many): each is pruned on its own, in parallel processes, and a list comes back in the same order; entries that are not fits with Fe II (a failed epoch) are returned as they are.
nsigmaa multiplet is kept if its amplitude is at least this many times its error.
n_jobsprocesses for a list of fits (-1: all cores but one; 1: serial).
fit_optionspassed to fantasy_agn.fit (default: the fitted range and the error method of result).
returnsthe new FitResult (result itself if nothing is dropped), with feii_pruning (the table) and feii_pruned (names of the dropped multiplets). The other attributes describe the new fit; compare bic with that of result.

fa.fit_epochs(spectra, model, shared=None, intercalibrate=True, wave_range=None, errors='covariance', scale_errors=True, reference='snr', calibration_degree=0, epoch_scaled=(), rescale_errors=False, calibration_limit=0.3, calibration_groups=None, wavelength_offsets=False, epoch_broadening=False, n_jobs=-1, verbose=True)

Fit several epochs of one object jointly.

spectralist of Spectrum (rest frame); mjd is used for light curves.
modelModel to fit to every epoch.
sharedparameter name patterns that are common to all epochs. Default: all narrow-line parameters and, if the model has a stellar host, the host (its starlight does not vary: one set of template weights, sigma* and v* for all epochs, which also makes the fit much faster). Add e.g. 'feii.fwhm', 'feii.shift' to also share the FeII kinematics.
intercalibratefit a flux scale factor per epoch (reference epoch = 1). Needs shared narrow lines to be meaningful.
referenceepoch that defines the flux scale: 'snr' (default, the epoch with the highest median S/N in the fitted range) or an index into spectra. The uncertainty of the reference enters every other epoch's calibration, so a high-S/N reference gives smaller errors.
calibration_degreewith intercalibrate, also a smooth wavelength-dependent calibration per epoch, s_k(lambda) = scale_k (1 + sum_j c_kj P_j(u)) with Legendre polynomials up to this degree over the fitted range (1: a tilt, 2: also curvature). SDSS flux-calibration errors depend on wavelength (fibre losses, differential refraction); a single scale per epoch (PrepSpec, Shen et al. 2016) leaves them in the light curves. The coefficients are anchored by the shared narrow lines (and host) across the range, so the model needs narrow lines at both ends (e.g. [OII] or Hbeta/[OIII] and Halpha/[NII]/[SII]).
epoch_scaledcomponents (e.g. ("host",)) whose shape is shared but whose amplitude is free in each epoch (<comp>.amp@k, 1 for the reference epoch): the host galaxy seen through different slits, fibres or seeing, e.g. spectra of a transient from several instruments. The component must also be shared (default for the host).
rescale_errorsmultiply the errors of each epoch by sqrt(reduced chi2) of its own independent fit (if > 1) before the joint fit, so that epochs with underestimated errors (e.g. smoothed or averaged spectra) do not dominate it.
calibration_groupslists of epoch indices (input order) observed with the same instrument and setting: they share the colour terms of calibration_degree (the overall flux scale stays free per epoch). Default: every epoch its own.
calibration_limitbound on the Legendre coefficients of calibration_degree (spectra from different instruments may differ in colour by more than 30%).
wavelength_offsetsfit a wavelength offset per epoch, as a velocity (km/s; reference epoch = 0) added to every shift of the model in that epoch (True: within +-150 km/s, or the limit in km/s). The epochs are never on exactly the same wavelength scale: the calibration of each spectrum differs by a few km/s (tens for slit spectra), and pipeline redshifts that differ from file to file (SDSS: ~20 km/s rms) move the spectra against each other when each is taken to the rest frame with its own. The shared narrow lines measure the offset of each epoch, as they measure its flux scale, so it needs a shared velocity (the default narrow.*). result.offsets lists them, and result.redshift() gives the redshift of the narrow lines.
epoch_broadeningfit an extra broadening per epoch, a FWHM (km/s) added in quadrature to every line width and to the stellar dispersion (reference epoch = 0; True: up to 300 km/s, or the limit in km/s; an epoch may also be sharper than the reference). The resolution differs between epochs (slit width, seeing, another spectrograph) and is often not known well; the shared narrow lines measure it. Without it a difference of resolution changes the shared narrow lines' fit in every epoch and so its flux scale. The widths in the epochs' results are intrinsic: each epoch's spectrum carries its broadened resolution. result.broadening lists them.
wave_rangefitted window (default: the model's).
errors'covariance' or None.
scale_errorsinflate errors by sqrt(reduced chi2) if > 1.
n_jobsprocesses for the independent fits that give the starting values (-1: all cores but one; 1: serial); see fantasy_agn.fit_many.
returnsMultiEpochResult
