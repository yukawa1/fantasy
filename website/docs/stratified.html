Stratified BLR profile

One physical profile for a broad line instead of a core plus a very broad Gaussian: a virialised broad-line region in which the velocity width falls with radius.

Gas at radius r has a Gaussian velocity distribution with FWHM ∝ r−1/2; the profile sums it from an inner to an outer radius with an emissivity per ln r ∝ r3−γ.

fwhm
the width at the outer edge (the core).
span
log10(rout/rin); the inner edge has FWHM·10span/2. span = 0 is a single Gaussian.
gamma
the emissivity slope; γ ≈ 3 gives Lorentzian-like wings.
fa.presets.hbeta(broad_components=1, broad_profile="stratified")
The innermost gas is faint and spread over very high velocities, so the inner edge is often below the noise: span then reaches its upper limit (2.5) and is a lower limit on the radial extent, while the outer width and γ remain well measured.
