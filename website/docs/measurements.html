FANTASY 2.0.2 / Measurements

Line measurements

Line quantities are measured on the fitted model profile of the line, summed over its components (for example two broad components), with errors propagated from the fit.
r.key_results()              # the main numbers with errors (what the app's summary shows)
r.lines                      # every line of every component: flux, FWHM, shift, EW, errors
r.fitted_lines()             # the lines that can be shown alone, most interesting first
r.measure("Hb")              # summed over all components containing Hβ
r.measure("Hb", ["broad", "broad2"])

For a profile P(v) on a velocity grid around the rest wavelength λ0:

Flux
F = ∫ P dλ
Shift
the flux-weighted centroid v̄ = ∫ v P dv / ∫ P dv
FWHM
between the outermost half-maximum crossings (interpolated), relative to the centroid
Line dispersion σ
σ2 = ∫ (v − v̄)2 P dv / ∫ P dv
EW
F / Fλ,AGN(λc): against the AGN continuum at the line (host excluded)

Widths are intrinsic: the instrumental resolution was removed in the fit. Lines with several components get their FWHM from the sum, not from the components.

Continuum and luminosities

r.continuum(5100)            # AGN continuum flux density
r.luminosity(5100)           # λLλ (erg/s), needs the flux unit and the redshift
r.host_properties()          # σ★, v★, age, metallicity, host fraction at 5100 Å
r.balmer_decrement()         # broad Hα/Hβ
r.model_flux(components=True)   # the model and each component on the data grid
r.to_dataframe()             # data, model, components, residuals in one table
